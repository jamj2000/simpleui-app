## Alert

> Mensajes cortos de distinto tipo.  


<Alert>
<strong>¡Información!</strong> Este es un mensaje informativo.
</Alert>

<Alert type="success">
<strong>¡Éxito!</strong><span>Este es un mensaje de éxito.</span>
</Alert>

<Alert type="warning">
<strong>¡Aviso!</strong> Este es un mensaje de aviso.
</Alert>

<Alert type="error">
<strong>¡Error!</strong> Este es un mensaje de error.
</Alert>

### Código de ejemplo

```js
<Alert type="info">
  <strong>¡Información!</strong><span>Este es un mensaje informativo.</span>
</Alert>
```

### Propiedades

<Prop name="type" value="info" values={["info", "success", "warning", "error"]} />
